# Generic Dash Support

Thank you for using Generic Dash.

## Supported ECUs

Generic Dash currently supports:

- LINK G4X
- Haltech

A compatible Generic Dash hardware device is required to receive live vehicle data.

## Support

If you experience a problem with Generic Dash, please contact us with the following information:

- Device model
- iOS / iPadOS version
- ECU type
- Generic Dash app version
- Description of the problem

## Privacy Policy

Please refer to the Generic Dash Privacy Policy for information about data handling and privacy.
