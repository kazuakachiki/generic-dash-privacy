# Generic Dash Privacy Policy

**Last updated: September 27, 2026**

Generic Dash respects your privacy. This Privacy Policy explains how information is handled when you use the Generic Dash mobile application.

## 1. Information Handled by Generic Dash

Generic Dash does not require a user account and does not collect personal information for advertising, cross-app tracking, or marketing purposes.

Generic Dash may process data received from compatible Generic Dash hardware, including:

- Vehicle and ECU data
- GPS data
- IMU and motion data
- Lap and sector data
- Recorded driving logs

This information is used to provide dashboard, data logging, map, lap timing, and driving analysis features.

Generic Dash does not automatically upload vehicle data, GPS logs, IMU data, or recorded driving logs to servers operated by the Generic Dash developer.

## 2. GPS and Location Information

Generic Dash does not use the mobile device's Location Services to determine the user's current location.

GPS information used by the app is received from compatible external Generic Dash hardware.

GPS information may be stored locally as part of recorded driving logs.

When the Online Map feature is enabled, Generic Dash retrieves map tiles corresponding to the displayed map area. As part of these requests, technical information such as the originating IP address, requested map tiles, User-Agent, and app or operating system information may be processed by the map service provider.

The requested map tiles may allow the displayed geographic area to be inferred.

Generic Dash does not upload the complete driving route or complete GPS log to the online map provider.

## 3. Local Network Communication

Generic Dash communicates with compatible Generic Dash hardware over a local Wi-Fi network.

This communication may include:

- Vehicle and ECU telemetry
- GPS data
- IMU data
- Device and application settings
- Diagnostic commands and information
- Firmware updates

This local communication is between the mobile device and the connected Generic Dash hardware and is not an upload of driving logs to a Generic Dash developer-operated Internet server.

## 4. Local Data Storage

Recorded logs and application settings are primarily stored on the user's device.

Generic Dash does not provide its own cloud synchronization service and does not automatically upload recorded driving logs to cloud storage.

Depending on the device and operating system settings, application data may be included in operating system backup or device migration services.

## 5. Advertising and Tracking

Generic Dash does not include advertising or advertising SDKs.

Generic Dash does not use vehicle or GPS data for cross-app advertising tracking.

Generic Dash does not sell vehicle logs, GPS logs, IMU data, or other recorded driving information to advertisers or data brokers.

## 6. Online Maps

Generic Dash uses MapLibre as map rendering technology and OpenFreeMap as an online map data provider.

When Online Map is enabled, network requests are made to retrieve the map resources required to display the selected geographic area.

OpenFreeMap may process technical information associated with these requests according to its own privacy practices.

OpenFreeMap Privacy Policy:

https://openfreemap.org/privacy/

## 7. Firmware Updates

Generic Dash may connect to GitHub when the user checks for or downloads firmware updates for compatible Generic Dash hardware.

GitHub and its associated delivery infrastructure may process information associated with these requests, such as IP address, requested resources, and HTTP technical information.

Generic Dash does not add vehicle logs, raw GPS coordinates, or ECU data to firmware update requests.

GitHub Privacy Statement:

https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

## 8. Data Management

Generic Dash does not provide its own cloud storage service for driving logs.

Data stored on the device may be managed or removed using file-management features provided by the operating system, clearing application data where supported, or uninstalling the application.

Available data-management options may vary depending on the operating system and device.

## 9. Third-Party Services

Generic Dash may use the following third-party technologies and services:

- MapLibre — map rendering technology
- OpenFreeMap — online map data provider
- GitHub — firmware update distribution

These services may process technical information associated with network requests according to their respective privacy policies.

## 10. Children's Privacy

Generic Dash is not specifically directed toward children and does not knowingly collect personal information from children.

## 11. Changes to This Privacy Policy

This Privacy Policy may be updated if Generic Dash functionality or data-handling practices change.

The latest version of this Privacy Policy will be made available through the official Generic Dash distribution or support information.

## 12. Contact

For questions about this Privacy Policy or Generic Dash, please use the developer support contact information provided on the application's store listing.
